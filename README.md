# NutriClass-Food-Classification-Using-Nutritional-Data
## Food Classification


NutriClass is a machine learning project that predicts food names using nutritional information.
The dataset contains different food classes with an imbalance in the number of samples.

**Data Preprocessing**

The following preprocessing steps were performed:
- Removed duplicate records
- Handled missing values
- Checked outliers
- Performed Exploratory Data Analysis (EDA)
- Encoded categorical features
- Handled class imbalance

**Machine Learning**

Different classification models were trained and evaluated, including:

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM
- XGBoost
- Gradient Boosting

**Streamlit Application**

A Streamlit application was developed for food prediction.

Users can enter nutritional information such as calories, protein, fat, carbohydrates, sugar, fiber, sodium, cholesterol, glycemic index, water content, and serving size.

Users can also select the meal type.

The trained machine learning model uses these inputs and predicts the food name.
